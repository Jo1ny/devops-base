# DevOps Base 🚀

Практический репозиторий для изучения фундаментальных технологий DevOps / DevSecOps, системного администрирования Linux, сетей и контейнеризации на живых примерах.

---

## 🛠 Стек окружения
* **ОС:** CachyOS (Linux kernel с x86-64-v3/v4 оптимизациями)
* **Shell:** Fish shell
* **Web:** Nginx (Alpine Linux)
* **Контейнеризация:** Docker, Docker Compose
* **Диагностика:** curl, ss, ip, journalctl, systemctl, ps

---

## 📌 Пройденные этапы (Completed)

### 1. Основы Linux и сетевая диагностика
* Работа со стандартными утилитами командной строки: `ps`, `pkill`, `cat`, конвейеры (`|`), перенаправление вывода.
* Сетевые протоколы и диагностика: TCP/UDP, DNS-резолвинг, анализ соединений через `ss -tulpn`, запросы через `curl`.
* Права доступа в Linux:
  * Математика прав (`r=4, w=2, x=1`).
  * Разделение user/group/others (`chmod 640`).
  * Битовая маска на директории (`+x` для входа и навигации) vs файлы.
  * Анализ рисков небезопасных прав (`chmod 777`).

### 2. Системные сервисы и веб-сервер Nginx
* Развертывание и конфигурирование Nginx на хостовой системе.
* Управление жизненным циклом демонов через `systemd` (`start`, `stop`, `reload`, `enable`).
* Разбор кодов ошибок HTTP (`200 OK`, `403 Forbidden`, `404 Not Found`).
* Диагностика инцидентов через логи (`journalctl -u`, `error.log`) и устранение конфликтов портов (`Address already in use`).

### 3. Контейнеризация (Docker & Docker Compose)
* Понимание архитектуры контейнеров: изоляция на уровне ядра Linux (cgroups + namespaces) без накладных расходов виртуализации.
* Управление контейнерами: `docker ps`, `run`, `stop`, `start`, `stats`, `logs`.
* Два способа доставки статики:
  * **Bind Mount:** монтирование локальной папки хоста (`-v /path:/path:ro`).
  * **Custom Dockerfile:** автономная сборка образа на базе `nginx:alpine` (`COPY site/ ...`).
* Оркестрация через **Docker Compose**: декларативное описание инфраструктуры в коде (`docker-compose.yml`) и автоматическое создание изолированной сети.
