## 🛠 Быстрая шпаргалка по диагностике

| Задача | Команда |
|---|---|
| Проверить физический/виртуальный линк | `ip link` |
| Показать все IP-адреса компактно | `ip -br addr` |
| Проверить слушающие TCP/UDP порты и процессы | `sudo ss -tulpn` |
| Проверить резолв доменного имени | `nslookup google.com` |
| Подробный HTTP-запрос | `curl -v http://localhost:порт` |
| Логи сервиса в реальном времени | `journalctl -u <имя_сервиса> -f` |
